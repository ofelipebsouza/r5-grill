# R5 Grill — Astro + Tailwind CSS
Site responsivo do restaurante R5 Grill de Loures. Proposta visual, ementa filtrável, pesquisa e seleção local; contactos por telefone e Uber Eats.

## Desenvolvimento
`npm install` e `npm run dev`. Produção: `npm run build`; saída `dist/`. Vercel: preset Astro.

## Páginas
- `/`: restaurante e 14 pratos
- `/marca`: guia visual e símbolo SVG
- `/instagram`: artes e conteúdos de campanha
- `/fontes`: origem da informação e limites de validação

## Conteúdo
Preços transcritos da foto fornecida, não confirmados como atuais. Contacto telefónico de diretório público. WhatsApp não confirmado e não implementado. Não há pedidos automáticos nem pagamentos. Fotos geradas sinalizadas como ilustrativas. A imagem original da fachada e ementa são fornecidas pelo utilizador.
